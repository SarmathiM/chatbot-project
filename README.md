# 🤖 SmartSphere Chatbot

## 📌 Description
A rule-based chatbot built using Flask that responds to user queries based on predefined patterns.

## 🚀 Features
- Rule-based responses
- Modern chat UI
- Dark mode 🌙
- User & bot message alignment
- Clean frontend design

## 🛠️ Technologies Used
- Python (Flask)
- HTML, CSS, JavaScript

## ▶️ How to Run
1. Install Flask:
   pip install flask

2. Run:
   python app.py

3. Open:
   http://127.0.0.1:5000/
